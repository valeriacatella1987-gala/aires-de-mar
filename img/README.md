# Cómo reemplazar las fotos

Carpeta destino: `D:\aires-de-mar\img\`

**Regla simple: para cambiar una foto, reemplazá el archivo con el MISMO nombre.**
No hace falta tocar el código — el sitio ya apunta a estos nombres.

| Archivo          | Dónde aparece                          | Forma / orientación recomendada |
|-------------------|-----------------------------------------|----------------------------------|
| `hero.jpeg`       | Foto grande de portada (arriba de todo) | Horizontal ancha (paisaje), buena luz |
| `casa1.jpeg`      | Sección "Nuestras casas" — foto grande  | Horizontal o cuadrada |
| `casa2.jpeg`      | Sección "Nuestras casas"                | Cuadrada |
| `casa3.jpeg`      | Sección "Nuestras casas"                | Cuadrada |
| `casa4.jpeg`      | Sección "Servicios" — juegos infantiles | Cuadrada |
| `interior1.jpeg`  | Sección "Nuestras casas" — interior     | Horizontal ancha |
| `interior2.jpeg`  | Sección "Servicios" — desayuno          | Vertical/cuadrada |
| `interior3.jpeg`  | Sección "Reservá" — interior            | Vertical |
| `piscina1.jpeg`   | Sección "Servicios" — piscina           | Vertical/cuadrada |
| `piscina2.jpeg`   | Sección "Reservá" — piscina             | Vertical |
| `parque1.jpeg`    | Sección "Servicios" — parrilla/parque   | Vertical/cuadrada |
| `parque2.jpeg`    | Sección "Servicios" — blancos/limpieza  | Vertical/cuadrada |
| `logo.jpg`         | Ícono de la pestaña del navegador       | Cuadrada, fondo simple |

## Recomendaciones
- Formato: `.jpeg` o `.jpg` (mantené la extensión que ya tiene el archivo).
- Peso: idealmente menos de 500KB por foto (así la web carga rápido). Si son más pesadas, no rompe nada, pero tarda más en cargar.
- Después de reemplazar: avisame y subo los cambios al sitio en vivo (GitHub + Vercel).

## ¿Querés agregar fotos nuevas (no reemplazar)?
Dejalas en esta carpeta con cualquier nombre y decime dónde querés que aparezcan — agrego el código para mostrarlas.
